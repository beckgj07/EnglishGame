【宝可梦版 伙伴素材槽说明】

一、目录用途
把官方宝可梦形象 PNG 放进本目录（E:/AI_Dev/AI_EnglishGame/demo/assets/pokemon/），
游戏会自动加载并替换手绘占位形象；未放置或文件名不匹配时，游戏自动降级为内置手绘 SVG 形象，不影响游玩。

二、文件命名约定（严格遵守，全部小写 + 下划线）
格式：pokemon_伙伴编号_进化阶段.png

伙伴编号（御三家三选一）：
  starter1 = 草系「妙蛙种子 → 妙蛙草 → 妙蛙花」✅ 三张官方图已就位（2026-10-16）
  starter2 = 火系「小火龙 → 火恐龙 → 喷火龙」✅ 三张官方图已就位（2026-10-16）
  starter3 = 水系「杰尼龟 → 卡咪龟 → 水箭龟」✅ 三张官方图已就位（2026-10-16）

进化阶段（宝可梦版共 3 阶）：
  _1 = 基础形态
  _2 = 第一阶（第一阶进化形态）
  _3 = 第二阶（第二阶进化形态）

示例（完整文件名清单，共 9 个槽位；starter1 三槽已填充）：
  pokemon_starter1_1.png   草系 · 妙蛙种子 ✅
  pokemon_starter1_2.png   草系 · 妙蛙草 ✅
  pokemon_starter1_3.png   草系 · 妙蛙花 ✅
  pokemon_starter2_1.png   火系 · 小火龙 ✅
  pokemon_starter2_2.png   火系 · 火恐龙 ✅
  pokemon_starter2_3.png   火系 · 喷火龙 ✅
  pokemon_starter3_1.png   水系 · 杰尼龟 ✅
  pokemon_starter3_2.png   水系 · 卡咪龟 ✅
  pokemon_starter3_3.png   水系 · 水箭龟 ✅

三、图片规格建议
  · 透明底 PNG（透明背景，不要白底矩形）
  · 建议 512×512 像素以上，正方形构图，形象居中
  · 单张 500KB 以内，保证手机加载流畅

四、展示方式
官方形象会以「贴纸贴在画本上」的形式呈现（自动加白色贴纸描边 + 轻微旋转），
与手绘纸质 UI 自然融合，无需自行处理背景。

五、扩展（后续版本）
若新增伙伴，编号继续 starter4、starter5……并在代码 CONFIG 区 PETS 中登记对应 key 与 slot。
